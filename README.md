# Learning Git & GitHub

Plan de 30 días para aprender Git y GitHub desde cero.

## Introducción

Este repositorio te guía paso a paso para aprender Git y GitHub de forma práctica y progresiva. Está pensado para principiantes que quieren empezar desde cero y fortalecer su flujo de trabajo con control de versiones, colaboración y publicación en GitHub.

## Estructura del curso

- [Semana 1: Fundamentos de Git](./semana-1.md)
- [Semana 2: Ramas, trabajo con repositorios y flujos básicos](./semana-2.md)
- [Semana 3: GitHub colaborativo y proyectos](./semana-3.md)
- [Semana 4: Git avanzado, limpieza y portafolio](./semana-4.md)

## Objetivo general

Al finalizar los 30 días, deberías ser capaz de:

- Inicializar y configurar repositorios Git.
- Crear commits con mensajes claros.
- Trabajar con ramas y fusionarlas con seguridad.
- Trabajar con repositorios remotos en GitHub.
- Hacer pull requests y colaborar en equipo.
- Manejar conflictos y recuperar cambios.
- Publicar proyectos personales y mantener un portafolio profesional.

## Recomendación de estudio

- Dedica 30 a 45 minutos al día.
- Practica cada comando en tu computadora.
- Haz notas de lo que aprendes.
- Crea proyectos pequeños para reforzar cada tema.
